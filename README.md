# Компьютерное зрение: методы глубокого обучения и лабораторный практикум

Электронные материалы к учебному пособию.

**Организация:** Московский технический университет связи и информатики (МТУСИ).
**Авторы:** К. Р. Харрасов, Т. Д. Потапченко, М. Г. Городничев, М. С. Мосева.

## Назначение репозитория

Репозиторий содержит сопровождающий программный комплект лабораторного практикума:
файлы требований с закреплёнными версиями пакетов, вспомогательные скрипты, конфигурацию
общего evaluator, описания наборов данных курса и скрипты их сборки, примеры форматов данных,
шаблон отчёта и контрольные тесты. Имена файлов и программные интерфейсы совпадают с
описанными в приложениях учебного пособия.

Текст учебного пособия в репозиторий не входит. Наборы данных и веса предобученных моделей
также не входят: для каждого из них указаны официальный источник, контрольная сумма и
порядок получения (`GET_DATA.md`).

## Лабораторные работы

| Работа | Тема | Данные и модели |
|---|---|---|
| ЛР1 | Свёртка и первая свёрточная сеть | Fashion-MNIST; MLP и CNN, обучаемые с нуля |
| ЛР2 | Пространство признаков и embeddings: визуальный поиск | Oxford-IIIT Pet (12 пород); ResNet18 |
| ЛР3 | Backbone и классификация: transfer learning и fine-tuning | Oxford-IIIT Pet; ResNet18 или MobileNetV3 |
| ЛР4 | Семантическая сегментация и пиксельная разметка | Oxford-IIIT Pet (trimap); LR-ASPP MobileNetV3-Large |
| ЛР5 | SAM и полуавтоматическая разметка с участием человека | Oxford-IIIT Pet; Segment Anything ViT-B |
| ЛР6 | Детекция объектов: YOLO и RT-DETR в едином протоколе оценки | Course edition на основе Pascal VOC 2007; YOLO11n, RT-DETR-L |
| ЛР7 | Foundation models, open-vocabulary детекция и pseudo-labels | Course edition на основе Pascal VOC 2007; CLIP, DINOv2, Grounding DINO, YOLO11n |

Подробнее о материалах каждой работы — в [`docs/LABS.md`](docs/LABS.md).

## Технологии и требования

- Python 3.12 (каноническая версия курса — 3.12.7; комплект проверен также на 3.12.0).
- PyTorch 2.11.0 и torchvision 0.26.0 (сборка для CPU); NumPy, SciPy, scikit-learn,
  Matplotlib, Pillow, pandas.
- ЛР5: segment-anything (закреплённый коммит репозитория); ЛР6: ultralytics 8.4.33 и
  pycocotools 2.0.11; ЛР7: transformers 5.16.1.
- Базовые маршруты всех работ выполняются без собственной видеокарты; для ЛР5–ЛР7 часть
  тяжёлого инференса заменяется предвычисленными результатами (bulk outputs).

Версии всех пакетов, включая зависимости, закреплены в `constraints.txt`; ревизии моделей
Hugging Face — в [`docs/MODELS.md`](docs/MODELS.md).

## Установка

Подробная инструкция — [`docs/INSTALL.md`](docs/INSTALL.md). Кратко, для Windows:

```
python -m venv .venv
.venv\Scripts\activate
pip install torch==2.11.0 torchvision==0.26.0 --index-url https://download.pytorch.org/whl/cpu
pip install -c constraints.txt -r requirements.txt
pip install --default-timeout=120 -c constraints.txt -r requirements-lr5.txt
pip install -c constraints.txt -r requirements-lr6.txt
pip install -c constraints.txt -r requirements-lr7.txt
pip check
```

В Linux и macOS окружение активируется командой `source .venv/bin/activate`. Пакеты ЛР5–ЛР7
можно устанавливать перед соответствующей работой. Для установки пакета ЛР5 нужен git.

## Данные и модели

Порядок получения наборов данных (Fashion-MNIST, Oxford-IIIT Pet, Pascal VOC 2007), весов
моделей и контрольные суммы приведены в [`GET_DATA.md`](GET_DATA.md). Course edition ЛР6 и ЛР7
собирается из официального архива Pascal VOC 2007 скриптом `data/build_voc_editions.py`; состав
частей задан файлами `manifest.json` в каталоге `data/`.

Формат предвычисленных результатов тяжёлого инференса для ЛР5 и ЛР7 описан в
[`docs/BULK_OUTPUTS.md`](docs/BULK_OUTPUTS.md). Публичный выпуск v1.0.1 содержит исходные файлы
и документацию без архива bulk outputs. Как выполнить работы без этого архива, включая
вычислительные требования и варианты получения результатов у преподавателя, указано в
[`docs/LABS.md`](docs/LABS.md).

## Контрольные тесты

Из корня репозитория:

```
python -m unittest discover -s tests -v
```

Тесты проверяют контрольные суммы файлов (`SHA256SUMS`), перекодирование trimap, общий
evaluator на учебном примере, обработку граничных случаев (пустой список предсказаний, boxes
нулевой площади, файлы JSON с кириллицей), режим ручного ввода каркаса сессии ЛР5 и форматы
данных курса. Наборы данных и веса моделей для тестов не нужны. Тесты evaluator требуют
pycocotools и пропускаются, если пакет не установлен.

## Сообщения об ошибках

Сообщения об ошибках и неточностях направляйте через раздел Issues репозитория. Укажите:
- номер работы и шаг либо имя файла и функции;
- версии Python и пакетов (вывод `pip freeze`) и операционную систему;
- точную команду и полный текст сообщения об ошибке;
- для ошибок в расчётах — минимальный пример данных, на котором ошибка воспроизводится.

Не прикладывайте к сообщениям решения лабораторных работ, личные данные и файлы наборов данных.
