# История выпусков

## v1.0.0

Первый стабильный выпуск сопровождающих материалов, соответствующий изданию учебного пособия.

- Файлы требований с закреплёнными версиями пакетов и `constraints.txt` с полным набором
  проверенных зависимостей; закреплённые ревизии моделей Hugging Face (`docs/MODELS.md`).
- Вспомогательные скрипты: `trimap_to_classids.py` (ЛР4, ЛР5), `sam_session.py` (ЛР5),
  `to_coco.py` и `coco_eval_config.json` (общий evaluator ЛР6, ЛР7).
- Общий evaluator `to_coco.py`:
  - boxes нулевой ширины или высоты отбрасываются адаптером `records_from_ultralytics`, их число
    записывается в поле `n_dropped`;
  - `check_records` сообщает о нарушениях формата исключением `ValueError`;
  - `evaluate` допускает пустой список предсказаний (определённые метрики равны 0), возвращает
    `None` для метрик групп без эталонных объектов, ключи `AR@1`, `AR@10`, `AR@100` и групповые AR;
  - файлы JSON читаются и записываются в UTF-8.
- Данные курса: список пород и разбиение Oxford-IIIT Pet, роли изображений ЛР5, manifest и
  скрипт сборки course edition ЛР6 и ЛР7 из Pascal VOC 2007, ontology ЛР7.
- `tools/make_lr5_bulk.py` — подготовка embeddings и кандидатов SAM для ЛР5.
- Примеры форматов, шаблон отчёта, инструкции по установке, данным, моделям и работам ЛР1–ЛР7.
- Контрольные и регрессионные тесты (`python -m unittest discover -s tests`).
